# Production Store Assets

This directory is reserved for approved production store artwork.

Do not add placeholder, mock, promotional, or unapproved artwork here.

Expected structure:

- `icon/app-icon-512.png`
- `feature-graphic/feature-graphic-1024x500.png`
- `screenshots/` — approved Google Play screenshots

The application metadata registry in `src/app/applicationMetadata.ts` is the single source of truth for the references and intended dimensions.
