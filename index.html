Game Help

Advanced Wall Drag Select Stone, Wooden, or Reinforced Wall. Drag from point A to B to build a snapped continuous row. Diagonal drags create an orthogonal corner automatically. Walls can cross uneven, forest, shore, and mountain terrain with stepped/sloped joints.
Wall Modules Choose Thin, Medium, or Thick in Wall Settings. Toggle Battlement and top Walkway independently. Click the same wall again to add another floor. Shift+click, [ key, or − Height lowers the selected section.
Modular Tower Builder Bases: Square, Round, Octagonal, Corner, Watch Tower. Tops: Battlement, Roof, Flat Platform, Flag, Watch Platform. Click the same tower again to add a floor; Shift+click lowers it. Towers snap directly into neighboring walls with no intentional gap.
Camera When a wall tool is active, left-drag builds walls. Use another tool for normal left-drag camera rotation. Right drag — Pan Mouse wheel — Zoom
Moats Select Moat and click buildable land. Workers automatically walk to the tile and excavate it. Connected moat tiles fill with water when they reach a river.
Settlement Roads connect edge-to-edge automatically. Four detailed house designs are available. Farms can be placed on plains.
Nature & Resources T — Add a tree · N — Grow mountain · M — Mine R — Add river · L — Add land · X — Remove Mines work on natural and player-built mountains.
Templates & Save Templates provides several starting settlements. Changes autosave after building. Save / Load uses browser local storage.
